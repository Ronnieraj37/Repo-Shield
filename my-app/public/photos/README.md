# Victim screenshots for the /demo presentation

Drop screenshots here (Reddit threads, the LinkedIn article, news coverage of
Contagious Interview / fake-interview scams). The demo page's "Real people, real
losses" section auto-displays whatever is present.

Name them: victim-1.png, victim-2.png, victim-3.png, victim-4.png (png or jpg).
Any slot with no file shows a labelled placeholder, so the section always looks
intentional. Recommended: wide screenshots, readable text, faces cropped/blurred
if you want to protect identities.
